Privacy Policy

Last updated: 29 September 2026

This policy covers the Penny Pop website and the Penny Pop uploader, a private tool the channel's owner uses to publish Penny Pop's own videos to its own YouTube channel.

Who uses the uploader

Only the owner of the Penny Pop YouTube channel. It is not a public app, and nobody else is asked to sign in to it.

What it accesses, and why

When the owner signs in with Google, the uploader asks for permission to manage the owner's YouTube channel through the YouTube Data API. It uses that permission only to:

  • read the signed-in channel's name and ID, to confirm it is uploading to the Penny Pop channel and no other;
  • upload Penny Pop's own finished videos, with their titles, descriptions and tags;
  • add caption files and thumbnails to those videos;
  • replace or remove an earlier upload of one of those videos, when the owner asks it to.

It does not read viewers' data, comments, subscribers, analytics or anything about other channels.

What is stored

The sign-in token Google issues is stored only on the owner's own computer, so uploads can run without signing in each time. It is never sent anywhere except to Google's own servers when making the API requests above. The uploader keeps a local record of which videos it has uploaded (their YouTube IDs). Nothing is sold, shared or sent to any third party.

Removing access

Access can be withdrawn at any time from the Google account's security settings, at myaccount.google.com/permissions, which makes the stored token useless. Deleting the token file on the owner's computer has the same effect locally.

YouTube and Google

The uploader uses YouTube API Services. By using it you are bound by the YouTube Terms of Service, and Google's handling of data is covered by the Google Privacy Policy.

The website

This website sets no cookies, runs no analytics and collects no personal information. It is hosted on GitHub Pages, whose own privacy statement applies to the servers it runs on.

Contact

Questions about this policy can be sent through the contact details on the Penny Pop YouTube channel.
